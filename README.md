# Gemstone Ores

Minecraft Java Edition **26.2**, Fabric, Java 25.

とびだせ どうぶつの森の鉱石をヒントに、ルビー・サファイア・エメラルド・アメジストの4種類を追加する非公式Modです。
金・銀は追加しません。既存のエメラルドやアメジストとは別の素材として扱います。

## 内容

- 4色それぞれに通常鉱石・深層鉱石・原石・収納ブロックを追加。
- 原石で剣・ツルハシ・斧・シャベル・クワ、防具4部位をクラフト。形は鉄装備と同じ。
- 道具の採掘性能・耐久値・攻撃性能、防具の防御力・耐久値は鉄相当。エンチャント可能。修理は同色の原石。
- 原石1個 → 鉄インゴット1個のクラフトで、バケツ・ハサミ・ホッパー・レールなど、鉄の全用途に使えます。鉄から原石へは戻せません。
- 原石9個 ⇔ 同色の収納ブロック1個。
- 採掘には鉄以上のツルハシが必要。幸運・シルクタッチ対応。鉱石はかまど・溶鉱炉でも処理できます。
- 日本語・英語表示、クリエイティブタブ、レシピブック対応。

## 出現率

オーバーワールドの**新しく生成するチャンク**に出現します。既存チャンクへの追加生成はしません。
26.2のダイヤの4種類の生成処理を基に、鉱脈の大きさ・高さ・空気露出時の抑制は同じにしています。

各色について、通常・中規模・埋没鉱脈の生成試行回数の期待値をダイヤの**1.2倍**にしています。
大型鉱脈はダイヤの1/9チャンクから1/7チャンクへ変更（約1.29倍）。
大半の生成はY=-64〜16、中規模鉱脈はY=-64〜-4で、深い場所ほど見つかりやすい設定です。
「約2割多め」は生成設定の期待値で、実際の鉱石数は地形・鉱脈の重なり・シードで変わります。
**4種類を合計した量ではなく、各種類をダイヤより少し多くしています。**

## 導入

1. Minecraft **Java版26.2**に[Fabric Loader](https://fabricmc.net/use/installer/) 0.19.5以上を導入。
2. 26.2向けの[Fabric API](https://modrinth.com/mod/fabric-api)をダウンロード。
3. `gemstone-ores-0.1.0.jar`とFabric APIのJARを、そのプロファイルの`mods`フォルダーに入れる。
4. Fabricのプロファイルで起動して、新規ワールドまたは未探索の場所で採掘する。

マルチプレイではサーバー・参加クライアント両方に同じModを入れてください。
Bedrock版には対応していません。初回はテスト用ワールドで確認してください。

## 開発

JDK 25を使用します。

```powershell
.\gradlew.bat build
.\gradlew.bat runClientGameTest
.\gradlew.bat runClient
```

ビルド成果物は`build/libs/`です。`-sources.jar`は開発用で、プレイには使いません。
Linux/macOSでは`bash ./gradlew`を使用します。
GitHub Actionsはpushごとにビルドと実際のシングルプレイワールドを使う結合テストを実行します。
結合テストは登録・装備の鉄との性能一致・タグ・レシピ・バイオームの生成設定を検証します。

生成済みJSONと画像はコミットしているため、通常のビルドにPythonは不要です。
リソースを再生成する場合のみ、Pillowを導入して次を実行します。

```text
python tools/generate_resources.py /path/to/26.2/minecraft-client.jar
```
